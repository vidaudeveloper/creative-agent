# 电商短视频 · 客户需求确认表（模板）

> 用途：接单 / 对接 / Agent 开做前，与客户确认「要做什么、给了什么、期望什么效果」。  
> 使用方式：复制「空白模板」填写；「填写示例」仅作参考，勿原样照抄。  
> 对齐文档：`COMMERCE-VIDEO-CASE-SUMMARY.md`

---

## 填写说明（给运营 / 对接同学）

1. **带 ★ 为必填**；其余按客户情况尽量补齐。  
2. 先勾选「需求类型」，再填产品和创意，避免一上来就写镜头。  
3. 「期望效果」尽量写成可验收的一句话，不要只写「好看一点」。  
4. 客户信息不全时，先追问再开做，不要空猜。
