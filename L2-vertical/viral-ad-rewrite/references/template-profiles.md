# Template profiles — what you may borrow

Classify the reference ad before writing the brief. Profile decides transfer slots and hard bans.

| Profile | Signals | Borrow | Do not borrow / invent |
|---------|---------|--------|-------------------------|
| `visual_product_texture` | Still-life, pour, texture, pack beauty, no talking head | Shot order, camera pacing, material/satisfaction beats, mood, music mood | VO/lipsync, person ethnicity, subtitle text from template |
| `human_demo` | Hands/person demo product, little or no VO | Demo gesture rhythm, reveal order, energy | Same face/identity; template wardrobe brand logos; pack text |
| `human_voiceover` | Presenter speaks / clear VO track | Hook timing, VO *pacing*, CTA style | Template VO wording; same person; subtitle burn-ins |
| `platform_cta` | End card, price sticker, “shop now” UI pattern | CTA timing & emphasis style | Exact UI chrome, prices, promo codes from template |
| `mixed` | Several mechanisms equally central | Only slots you list explicitly in the brief | Anything not listed |

## Ambiguity (human templates)

If mouth moves but audio role is unclear → **block** generation. Ask user:

- A) Treat as `human_demo` (no VO)
- B) Treat as `human_voiceover` (language = template spoken language)

Do not silently pick.

## Product image guidance

- Prefer pack / product-only heroes (no clear real face) for stability and risk
- If user only has face+product UGC, warn and ask for a cleaner pack shot when possible
- Product image always wins on: color, shape, logo, visible on-pack claims

## Transfer checklist (put into brief)

For the chosen profile, list concrete borrow bullets, e.g.:

- Open on extreme close-up texture → pull back to hero pack (3s)
- Mid beats: three satisfaction cuts at ~2s each
- End on held pack + soft CTA gesture (not template’s price tag)
