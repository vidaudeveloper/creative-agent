# 电商付费客户需求复盘与 Creative Agent 规划

> 来源：VidAU 电商付费客户成功素材复盘  
> 阅读对象：业务 / 产品决策  
> 本文主线：**客户要什么 → 能提供什么信息 / 怎么提需求 → 期望做成什么样 → 实际做成什么样 → 对照现有 Agent 怎么规划**

---

## 1. 结论先看

付费电商客户的需求，本质不是「随便做一条好看视频」，而是：

**用有限的产品信息，按某种带货意图，做出能停滑、能证明、能下单的短视频。**

对照现状：

| 维度 | 付费客户真实情况 | 现有 Agent 大致能力 | 差距判断 |
|------|------------------|---------------------|----------|
| 需求类型 | 转化为主，形态分实拍 / 混剪 / AI / 品牌宣传 | 能做商品广告、爆款结构复刻、趋势钩子、口播等 | 形态能覆盖，但「按需求类型选打法」还不够稳 |
| 产品信息 | 常有卖点、参数、场景，素材完整度参差 | 可从链接/图片抽取卖点与参考图 | 对「顾虑、实测点、价格/买赠、本地化」抓取与追问不足 |
| Prompt / 提法 | 多为目标导向（要转化、要实测感、要大片感） | 偏通用 Hook→卖点→CTA | 缺少按需求类型的提示词与结构模板 |
| 期望效果 | 前几秒留存高、点击/转化达标 | 能出片，质量标准未强制对齐投放指标 | 缺「期望 vs 成片」的质检闭环 |
| 实际效果 | 优片前 5 秒留存可到 60%+，转化 3%–4%+ | 尚未用同一套投放标准验收 | 应用客户成功样本做回归标尺 |

## 2. 客户需求类型（先分清要做什么）

按本次案例，付费客户需求可归为 **3 大类形态 × 1 个主目标**：

### 2.1 主目标（几乎一致）

**商品转化（带货）** —— 种草 / 品牌心智是手段，下单是目的。  
少数 AI 案例属于 **品牌宣传 / ToB 宣传**，与带货分流。

### 2.2 需求类型总表

| 需求类型 | 客户在说什么（典型意图） | 代表品类 | 案例量级 |
|----------|--------------------------|----------|----------|
| A. 实拍转化 | 「要真实、要实测、要打掉顾虑、要能投」 | 3C、女包、凉鞋、暖手宝、厨清、按摩、卡包、运动内衣/耳机 | 约 30+ 条，主体 |
| B. 混剪转化 | 「要大片感、多色系、系列感、抬客单」 | 女装 / 包袋 | 约 3 条 |
| C1. AI 带货 | 「没那么多实拍预算/素材，但要可投广告」 | 香水、美妆、牙贴、湿巾、女装、美容仪、运动表等 | 约 22 品次 |
| C2. AI 品牌/TVC | 「要品牌调性或业务宣传，不硬推下单」 | 美妆 TVC、ToB、显示器、车灯 | 约 7 品次 |

### 2.3 实拍转化里的子需求（更细的客户诉求）

| 子类型 | 客户真实诉求 | 案例信号 |
|--------|--------------|----------|
| A1 性能实测型 | 把参数做成「一眼懂」的实验 | 吹风机吹水、手表水洗、续航时间具象化 |
| A2 痛点解决型 | 先拍痛，再给解法 | 凉鞋脚痛、耳机跑步掉落、水槽油垢、天冷手冻 |
| A3 质感溢价型 | 证明「配得上这个价」 | 女包微距、凉鞋水钻珍珠、开箱仪式感 |
| A4 一物多用型 | 证明「买一个顶好几个」 | 卡包支架、充电线隐形支架、清洁刷多刷头 |
| A5 人群/场景型 | 证明「适合我这种人/这种场合」 | 运动内衣真实身形、差旅干发、职场托特包 |
| A6 感官停滑型 | 先让人停住再讲功能 | 键盘 ASMR、清洁解压画面 |

## 3. 客户能提供的产品信息（输入侧）

案例本身很少贴原始 Brief，但从成片可反推：**客户侧通常能提供 / 需要补齐的信息分层如下。**

### 3.1 信息分层

| 信息层级 | 常见是否具备 | 具体内容 | 对成片的影响 |
|----------|--------------|----------|--------------|
| 基础产品信息 | 高 | 品类、外观、核心卖点 2–4 条、关键参数 | 没有则无法做「像这个 SKU」的片 |
| 使用与场景 | 中高 | 给谁用、什么场景、解决什么麻烦 | 决定开场痛点与生活化镜头 |
| 购买顾虑 | 中（常需运营帮挖） | 噪音、掉落、变形、安全、假货感、尺码 | 决定要不要加「打消顾虑」段落 |
| 素材资产 | 参差 | 实拍成片素材 / 模特图 / 静物图 / 仅包装图 | 决定走实拍、混剪还是 AI |
| 转化要素 | 中 | 价格、买赠、地区语言、CTA 文案 | 影响收口与本地化 |
| 风格参考 | 低～中 | 「要像某条爆款」「要大片/UGC/实测」 | 影响结构选择，不是必填 |

### 3.2 按需求类型：最低要齐什么

| 需求类型 | 最低产品信息 | 有了会明显更好 | 没有时的风险 |
|----------|--------------|----------------|--------------|
| A 实拍转化 | 卖点 + 参数 + 顾虑 + 使用场景 | 可拍的实测点、真人/实拍素材 | 容易变成空口播卖点，留存差 |
| B 混剪转化 | 多色/多款图 + 材质卖点 | 模特穿搭、系列 SKU | 容易「好看不转化」 |
| C1 AI 带货 | 产品主图 + 卖点 + 合规边界 | 使用前后、场景图 | 容易只剩氛围，缺少证据感 |
| C2 AI 品牌/TVC | 品牌调性、宣传要点 | 业务场景、禁用硬广要求 | 做成带货片会跑偏 |

### 3.3 建议对外统一收集的「客户输入清单」

以后接客户或 Agent 追问，建议固定问这些（比空泛「请描述需求」更有效）：

1. **产品是什么**：品类、名字、卖点 3 条、关键参数  
2. **卖给谁、用在哪**：人群 + 场景  
3. **用户最怕什么**：1–2 条顾虑  
4. **手上有什么素材**：实拍 / 模特 / 静物 / 仅产品图  
5. **要什么结果**：更看重停留、点击，还是转化  
6. **怎么收口**：是否露价格、买赠、地区语言  
7. **想做成哪种片**：实测感 / 大片混剪 / AI 氛围 / 参考某条爆款

## 4. 客户怎么提需求（Prompt / 需求表述类型）

客户很少写「标准 Prompt」，更多是目标导向的一句话。可归纳为以下几类提法，以及背后真正要 Agent 理解的东西：

| Prompt / 提法类型 | 客户原话近似 | 真正要求 | 对应需求类型 |
|-------------------|--------------|----------|--------------|
| 转化导向 | 「做一条能投的带货」「要转化」 | 完整链路：停滑→证明→下单 | A / B / C1 |
| 实测导向 | 「把 16 万转拍出来」「防水要看得见」 | 必须有可视化证明镜头 | A1 |
| 痛点导向 | 「先拍脚痛再拍鞋」「跑步耳机老掉」 | 开场必须是痛，不是参数 | A2 |
| 质感导向 | 「要高级感」「水钻要闪」 | 微距与光影优先于功能罗列 | A3 / B |
| 场景导向 | 「通勤能装电脑」「差旅也要用」 | 多场景，不只棚拍 | A5 |
| 结构复用 | 「参考这条爆款做我们的」 | 借节奏结构，不借品牌话术 | A / B + 复刻 |
| 氛围/品牌 | 「做 TVC 感」「ToB 宣传」 | 弱硬广，重调性 | C2 |
| 素材受限 | 「只有产品图」「来不及实拍」 | 走 AI / 混剪，但仍要转化结构 | B / C1 |

**对 Agent 的含义**：不能只吃「产品卖点列表」，还要识别客户属于哪类 Prompt，再决定开场、证据、形态。

## 5. 期望效果 vs 实际效果

### 5.1 客户期望效果（从成片意图还原）

| 期望层 | 客户心里要的效果 | 案例中的常见表达 |
|--------|------------------|------------------|
| 停留 | 前几秒别被滑走 | 暴力实测、痛点、悬念、第一视角 |
| 信任 | 相信好用/耐用/值这个价 | 仪器实测、装载、回弹、安全细节 |
| 欲望 | 觉得「这就是我的生活」 | 多场景、穿搭、礼赠/开箱 |
| 行动 | 点进去、下单 | BUY NOW、价格、买赠 |
| 品牌（少数） | 抬调性、讲业务 | AI TVC / ToB |

### 5.2 实际效果（投放结果区间）

**实拍优片常见表现**

| 指标 | 优效参考 | 说明 |
|------|----------|------|
| 前 5 秒留存 | ≥ 60% | 开场成立 |
| 点击率 | ≥ 5%–6% | 想点进去看/买 |
| 转化率 | ≥ 3%–4% | 信任与价格闭环 |
| 有效观看 | ≥ 20%–25% | 愿意被说服 |
| 播放量 | 数十万～200 万+ | 与投放量相关，作参考 |

**混剪**：播放与停留不差，转化略低于顶尖实拍痛点片，更适合抬质感与系列种草。  
**AI 带货/TVC**：形态已验证可做；本次材料缺少统一投放数字，不宜直接与实拍比转化，但「带货仍需证据+收口」的结论成立。

### 5.3 期望 vs 实际：对照看差距从哪来

| 若客户期望… | 实际容易做成… | 常见原因 | 对 Agent 的要求 |
|-------------|--------------|----------|-----------------|
| 高停留 | 前 3 秒在念卖点 | 没有可拍钩子 | 强制开场画面，不只文案 |
| 高信任 | 只罗列参数 | 没有实测/对比 | 必须设计「看得见的证据」 |
| 高转化 | 好看但无收口 | 做成氛围片 | 片尾必须有行动引导 |
| 大片感 | 空镜堆砌 | 无选购矩阵 | 混剪也要色系/系列收口 |
| 像爆款 | 抄画面或抄品牌 | 理解成「复制」 | 只借结构，产品必须是客户的 |
| 只有产品图也要转化 | AI 纯展示 | 缺痛点与证据模拟 | AI 也走同一卖货链路 |

### 5.4 几类典型「输入 → 期望 → 实际」样本（便于对齐认知）

| 客户类型 | 大致能提供的信息 | 需求提法 | 期望效果 | 实际效果（样本） |
|----------|------------------|----------|----------|------------------|
| 3C 吹风机 | 高转速、低噪、差旅场景 | 「性能要一眼看出」 | 前几秒建立专业信任并转化 | 播放百万级；前 5 秒约 58%–62%；转化约 2.8%–3.5% |
| 女式凉鞋 | 舒适、水钻/珍珠、多穿搭 | 「痛点开头 + 要闪 + 要百搭」 | 高点击高转化 | 前 5 秒可达 64%+；点击约 7%–8%；转化约 3.8%–4.1% |
| 运动内衣 | 真实身形、防震、日常也能穿 | 「真实穿着 + 运动测 + 不只健身房」 | 高停留高转化 | 播放约 218 万；前 5 秒约 68%；转化约 4.2% |
| 厨清电动刷 | 多刷头、去污、省力 | 「先拍脏、再看刷净」 | 解压证明 + 转化 | 播放相对更小，但转化可达约 4%+ |
| 女装/包袋混剪 | 多色静物/模特 | 「大片感、系列感」 | 抬溢价、带动选购 | 播放 140 万+；停留高；转化约 2.9% |
| AI 美妆/个护等 | 以产品图为主 | 「做出可投广告/品牌片」 | 可投放、有调性 | 形态可交付；投放指标待补齐后复盘 |

## 6. 对照现有 Creative Agent：会什么、缺什么

### 6.1 现有 Agent 已具备（相对客户需求）

- 从商品链接 / 图片理解产品并做广告向短视频  
- 通用卖货结构：开场 → 卖点 → 行动号召  
- 部分品类手册（如美妆、服饰、食品）  
- 爆款结构复刻、趋势换钩子、口播等路径  
- 确认后再生成，降低瞎出片  

### 6.2 相对付费客户样本的主要缺口

| 缺口 | 表现 | 影响 |
|------|------|------|
| 需求类型识别弱 | 客户说「要转化/要实测/要大片」时，未稳定分流到 A/B/C | 容易用同一套模板打所有单 |
| 输入信息挖不深 | 对顾虑、实测点、价格买赠、素材完整度追问不足 | 成片缺证据、缺收口 |
| Prompt 理解偏文案 | 更吃「卖点列表」，不够吃「目标型一句话」 | 开场弱、形态选错 |
| 期望效果无标尺 | 未用前 5 秒/点击/转化思维做自检 | 「能出片」≠「像付费优片」 |
| 实拍逻辑难复现 | 暴力实测、装载、解压清洁等强证明镜头，Agent 易弱化 | 3C/工具类信任不足 |
| AI/混剪易空心 | 好看但缺转化闭环 | 与客户「要能投」目标错位 |

## 7. 规划建议（用客户样本反推 Agent 该补什么）

### 7.1 规划原则

1. **先对齐客户需求类型，再谈生成。**  
2. **先齐输入信息，再齐效果标准。**  
3. **用付费优片当验收尺子，不用「是否出片」当完成。**

### 7.2 三步规划

#### 第一步：需求识别与输入齐套（优先）

- 让 Agent 先判断：实拍转化 / 混剪转化 / AI 带货 / 品牌宣传  
- 再判断子类型：实测、痛点、质感、一物多用、场景、感官  
- 按第 3.3 节清单补齐产品信息；缺「证据点」或「顾虑」必须追问  
- **验收**：给吹风机 / 托特包 / 仅产品图美妆三类需求，能正确分流并列出信息缺口  

#### 第二步：按需求类型固化「期望效果」标准

- 带货类统一要求：有停滑开场、有可见证据、有转化收口  
- 混剪类额外要求：系列/色系选购感，禁止纯氛围  
- AI 带货同样走卖货链路；AI 品牌宣传才允许弱化硬广  
- **验收**：出片前能用第 5.1 / 8 节标准自检，不合格先改方案  

#### 第三步：用客户成功样本做效果对齐

- 锚定样本：运动内衣、运动耳机、凉鞋、3C 实测、厨清解压、混剪女包、AI 带货各至少 1 类  
- 对比「客户期望 / 优片实际」与「Agent 当前输出」  
- 差距优先补：开场强度、证据镜头、顾虑回应、收口转化  
- **验收**：同上品类抽检，业务侧认为「方向像付费片」，而不是「另一套通用广告腔」  

### 7.3 规划优先级一览

| 优先级 | 规划项 | 对应客户问题 | 完成后的变化 |
|--------|--------|--------------|--------------|
| P0 | 需求类型分流（A/B/C + 子类型） | 客户提法不同，片子却一个味 | 提法能映射到正确打法 |
| P0 | 产品信息齐套追问 | 客户信息不全就开做 | 少做空卖点片 |
| P0 | 期望效果质检（停留/信任/转化） | 只求出片 | 按付费标准卡质量 |
| P1 | 五类高表现结构沉淀 | 「参考爆款」「要实测」说不清 | 有可复用结构，不抄品牌 |
| P1 | 混剪 / AI 的转化闭环 | 好看不转化 | 形态不同，卖货目标一致 |
| P2 | AI 案例补投放数据后再调优 | AI 效果好坏说不清 | 用数据校准，而不是感觉 |

### 7.4 建议的推进节奏（业务里程碑）

| 阶段 | 目标 | 完成标志 |
|------|------|----------|
| 阶段一 | 认清需求、问清信息 | 客户一句话需求能归类；缺信息会追问 |
| 阶段二 | 按类型做出「像付费片」的方案 | 方案里必有开场、证据、顾虑、收口 |
| 阶段三 | 用成功客户样本抽检 Agent 成片 | 与第 5.4 节样本方向对齐，而不是仅「能生成」 |

---

## 8. 出片期望效果清单（给业务验收用）

无论实拍、混剪还是 AI 带货，交付前建议统一问：

1. 客户属于哪种需求类型？是否选对形态？  
2. 产品信息是否齐（卖点、场景、顾虑、素材、收口）？  
3. 开场 3 秒有没有停滑画面？  
4. 有没有至少一条看得见的证据？  
5. 有没有回应主要购买顾虑？  
6. 结尾有没有明确转化动作（品牌宣传类除外）？  
7. 与客户原话期望是否一致（实测 / 大片 / 参考爆款 / 仅产品图等）？
