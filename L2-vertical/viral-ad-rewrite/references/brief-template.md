## Detailed analysis (when asked)

Expand without skipping the next-step gate:

1. Template facts (hook, pacing windows, CTA style)
2. Rough shot timeline (every ~5s if possible)
3. Product-image analysis (anchors)
4. Proposed generation script outline
5. Constraints + forbidden list again
6. Re-offer: confirm / edit

## Confirmation phrases

Treat as confirm only when explicit: “确认生成”, “confirm”, “就按这个出片”, “OK generate”.

Edits (“语气轻松点”, “换 CTA”) → patch brief → show refreshed compact brief → wait again.

## Never omit

- Fewer than 3 borrow or 3 forbid bullets
- Jumping to MCP generate from `START_OPENING`
- Dropping the confirm/edit options after an edit
